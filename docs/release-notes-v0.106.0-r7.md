# Trilium Notes for fnOS v0.106.0-r7

完整原生应用包，内置官方 Trilium 0.106.0 Linux Server 与 Node.js，无 Docker 依赖。

## 主要修复

- 飞牛网关的整套官方脚本、样式、主题、字体和依赖资源改用版本化新目录，避开手机 FN Connect 通道中异常的旧资源缓存；不重定向回旧地址，不修改官方程序正文。
- 请求后端使用 identity；后端仍压缩时正确解压，传递完整资源字节和准确长度。新资源目录采用 no-store/no-transform，不复用旧验证器。
- iPhone 飞牛 App 页面单次延后启动官方模块入口，保持原有主题和界面；不重放笔记、登录或同步请求。
- 修正生命周期对物理安装路径和系统别名的识别，保留严格进程身份核验，避免将自身进程误判成端口占用。
- 保留电脑端同步页面和地址、笔记库及原认证；关闭一次性诊断与模块实验入口。没有在线更新按钮，以后通过新 FPK 手动升级。

## 验证与已知情况

134 项自动化测试通过；x86_64 与 ARM64 FPK 各 2908 个官方文件逐字节匹配上游归档，校验属主、归档结构、运行模式和校验和。

2026-10-11 用户反馈安装 r7 后 iPhone 飞牛 App 已正常使用。该反馈限于用户实际设备和网络，不代表所有平台已覆盖；ARM64 尚无实机启动反馈。打开后笔记内容仍有约 2–3 秒等待，未单独测量原因。

## 安装

按 NAS 架构下载对应 FPK，核对 SHA256SUMS。在应用中心停止旧应用后安装新包；**升级不用卸载，不要删除数据，先备份笔记**。误卸载后恢复安装请选择原存储卷，前提是数据已保留。

安装后关闭旧页面并重新打开。默认电脑端同步地址仍为 `http://NAS固定IP:8080/`；18888 仅用于本机后端，不作为同步地址。详情见仓库 README 和 r7 安装说明。

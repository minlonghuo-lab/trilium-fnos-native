# 0.106.0-r1 验证记录

验证日期：2026-10-08（Asia/Shanghai）。安装包发布于 GitHub Releases，源码与校验记录随仓库提交。

## 已验证

- 38 项 Node/Shell 回归测试通过：鉴权、Cookie 隔离、网关、WebSocket、同步请求透传、更新接口移除、只读同步页、启动进程身份、锁、手动升级冷备份与安装幂等性。
- 0.106.0 官方入口为 main.mjs；生命周期同时支持旧 main.cjs，不修改官方程序。
- x86_64、ARM64 两个 FPK 均完成校验，每包 2,908 个官方文件逐字节匹配对应 Release 归档。
- 最终 FPK 的代理、同步页和生命周期脚本与工作区一致；包内不存在旧更新控制器、恢复模块、维护状态模块与更新前端。
- 最终版本、开发者、发布者及链接已核对；两包 SHA-256 与 dist/SHA256SUMS 一致。
- Playwright Chromium：菜单进入独立同步页，390×844 手机视口、1280×900 桌面视口，浅色/深色，复制成功，无 Clipboard API 时手动复制回退，模拟 HTTP 503 后重试恢复。
- 正常页面控制台无错误、无警告；故障注入产生的 503 网络错误符合测试预期，无未处理脚本异常。

## 视觉核对

依照用户确认的初稿与 web-design-engineer 流程，复用官方图标、主题变量及紧凑设置页结构。已人工查看手机浅色与桌面深色截图，无横向溢出，未引入悬浮操作或更新控件。

截图保存在 output/playwright/，不随 FPK 发布；截图地址为开发 fixture 的模拟数据，并非实际 NAS 地址。

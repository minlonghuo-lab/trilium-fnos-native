# v0.106.0-r7 完整恢复安装包

## 安装前须知

此版本是包含资源命名空间及生命周期修复的完整原生 FPK，不是需依赖旧安装的补丁。Trilium 本体仍为官方 0.106.0，没有 Docker、在线更新器或悬浮按钮。代码及两架构 FPK 随 GitHub r7 发布提供。

常规升级无需卸载。误卸载后只有在 fnOS 保留了原应用数据的情况下，才可能通过同卷重新安装恢复；若卸载时删除了数据，需从备份恢复，不能由安装包重建笔记。安装回调不主动清理或初始化已有数据库。

1. 先在 NAS 中备份保留的数据目录（含数据库、WAL、配置），不要删除或移动原目录。
2. Intel/AMD NAS 使用 `trilium-fnos-v0.106.0-r7-x86_64.fpk`，ARM64 NAS 使用对应 ARM64 包。**恢复安装时选择原来的存储卷**，应用名仍为 trilium-fnos，才能复用原数据路径与运行时链接。不要选择清除数据。
3. r7 已直接包含修复代码，无需额外执行临时热修复部署脚本。
4. 安装后先确认应用中心启用成功，浏览器中原笔记仍可打开。若出现全新数据库初始化向导，不要创建新库或设置新密码，应停止并核对保留的数据路径。
5. 在 iPhone 飞牛 App 关闭旧 Trilium 页面，再通过 FNID 重新打开并测试登录、笔记编辑。无需清空手机 App 数据。失败时记录错误和时间，保留代理日志。

## 修复范围

- 完整公开静态树改用版本化新地址；资源正文保留官方字节，拒绝路径穿越和私密文件访问，不跳回旧 URL。
- 保留登录/API/笔记附件和直连同步地址；内部后端仍 127.0.0.1:18888，默认外部同步入口为 NAS IP:8080。
- iPhone App 单次延后启动官方入口，仍沿用 Trilium 原生主题及同步页。
- 生命周期识别正确处理物理路径与系统别名，严格检查进程实际可执行文件和第二个入口参数，不按端口杀进程。
- 不启用一次性诊断记录及模块实验入口，不修改全局 nginx、鉴权或笔记数据库。
